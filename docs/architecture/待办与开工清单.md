### 决策 D-3（待确认）：勾设备时高危写动作是否对 LLM 可见

**议题**：Agent 勾选设备（`enabled_devices`）后，该设备下 **封禁/处置类写动作**（`risk_level=high_risk` 或 `category∈{block,dispose}`）是否默认装配给 LLM。

**前置**：设备对接时在 `DeviceAction` 标好 `category`、`risk_level`（模型已有字段）。

| 选项 | 含义 | 适用 |
|------|------|------|
| **A** 勾设备=全装配 | 高危写动作随设备默认暴露 | MVP 配置简单；靠 verification 兜底 |
| **B** 高危单独勾 | 勾设备仅只读/查询；写动作另勾一层 | 防对话误封；设备动作列表需标等级 |
| **C** 折中 | 语义 `block_ip` 核心可见；细粒度投影走 `tool_search` | 平衡易用与上下文 |

**待决方**：产品 / 安全运营（项目负责人暂不拍板）。**不阻塞** D-1、D-2 与阶段 0。
