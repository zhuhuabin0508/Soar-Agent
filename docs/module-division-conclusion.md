# SOAR 五大模块分工结论（对用户友好版）

> 一句话定调：
> **智能体是「老板」（决定怎么想、谁来干活、何时收尾）；工作流是「剧本」（把固定步骤写成可执行流程）；工具是「双手」（能做什么动作）；技能是「工作手册」（教老板按流程思考）；知识库是「参考资料」（需要时去查）。**

---

## 一、五大模块分工表

| 模块 | 一句话定位 | 负责什么 | 不负责什么 |
|------|-----------|---------|-----------|
| **智能体 Agent** | 编排中枢 | 选模型、定提示词、决定启用哪些能力 | 不直接写死执行步骤 |
| **工作流 Workflow** | 固化流程 | 把确定步骤串成可执行节点图、定时/事件触发 | 不适合频繁临时发挥 |
| **工具 Tool** | 动作能力 | 提供可调用动作（查资产/封禁/发消息/扫描） | 不管"怎么想"，只管"做什么" |
| **技能 Skill** | 方法论 | 注入提示词，教模型"按什么步骤/标准思考输出" | 不产生可调用动作 |
| **知识库 KB** | 领域信息 | 提供文档/向量数据，模型按需检索 | 不替代思考，只提供依据 |

**核心原则**：`技能`+`提示词`管「怎么思考」；`工具`+`知识库`管「能做什么 / 知道什么」。

---

## 二、遇到场景时怎么选（决策规则）

| 场景 | 选择 |
|------|------|
| 快捷灵活、让 AI 自己发挥 | **智能体 + 技能/提示词** |
| 稳定可复用、必须按标准走 | **工作流**（固化成节点） |
| 想要某个具体动作 | 建/勾选 **工具** |
| 教模型按一套 SOP 流程走 | 写 **技能** |
| 让模型能查规章/历史数据 | 挂 **知识库** |

---

## 三、最该改对的 3 个点

1. **新建时二选一**：明确区分「对话智能体」和「工作流」，一个靠 AI 自主、一个靠固定流程，入口分开。
2. **工具按「包」管理**：把工具按类别打包（安全/资产/封禁/文档），智能体按包勾选。
3. **资产检索只走一条路**：`search_assets` 不再"既在工具表又靠资产类型单独驱动"，统一成"勾选工具即生效"。
