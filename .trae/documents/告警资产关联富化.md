# 告警关联本地资产库（资产与主体富化）

## Context

告警列表/详情的「资产与主体」分组没有本地资产信息：告警只存解析出的原始字段（XDR 告警 host_ip 32/42 有值，asset_id 是 XDR 侧资产 ID），与本地资产库 `assets` 表（96,890 行）无任何关联机制。现有 `AssetEnricher`（enricher_stage.py）匹配的是 devices 设备表且默认未启用、结果不落库。

需求（用户已确认）：
- 告警入库时按 IP 匹配资产库，**host→src→dst 逐级兜底**（实测命中率 41/42 = 98%）
- 「关联资产」展示**名称 + 点击跳转**（跳转资产列表并自动搜索）
- 资产库 IP 形态：单 IP 91,006（96.6%）+ CIDR 2,644 + IP 范围 733 + 多值 79，需支持网段包含匹配

## 实现步骤

### 1. 新富化器 AssetLibEnricher（匹配 assets 资产库）
文件：`backend/app/core/log_receiver_manager/pipeline/enricher_stage.py`

- 新增类 `AssetLibEnricher`（name="asset_lib"，与现有 AssetEnricher 并存，旧的保留不动）
- **资产索引内存缓存**（模块级）：
  - 构建方式：`SELECT id, name, ip FROM assets WHERE ip IS NOT NULL AND ip != ''`，解析为 `{单IP: (id, name)}` dict + `[(ip_network 或 (起,止) 范围, id, name)]` 列表（`ipaddress` 模块）
  - TTL 10 分钟；提供 `invalidate_asset_index()` 供资产写接口主动失效
- **匹配逻辑**（`enrich(norm, db)`）：
  - 依次取 host_ip → src_ip → dst_ip，每个字段解析 JSON 数组（过滤 `fe80::` 链路本地 IPv6），最多前 5 个 IP
  - 单 IP 精确匹配优先，未命中再遍历 CIDR/范围（网段列表按网络地址排序，线性判断）
  - 命中即停，`norm.set_field()` 写入（仅补空不覆盖）：`relate_asset_id` / `relate_asset_name` / `relate_asset_ip`（命中所用 IP）
- `pipeline_default.json`：`enricher.enrichers` 默认 `["asset_lib"]`（全局启用）

### 2. AlertEvent 模型 + 轻量迁移
- `backend/app/models/alert_event.py`：新增 3 列
  - `relate_asset_id = Column(Integer, nullable=True)`
  - `relate_asset_name = Column(String(255), default="")`
  - `relate_asset_ip = Column(String(64), default="")`
- `backend/app/core/security.py` 的 `run_lightweight_migrations`：按现有 `ensure_columns` 模式补 `alert_events` 三列

### 3. 告警序列化
- `backend/app/api/v1/alerts.py` 的 `_serialize`：新增输出 3 字段（列表与详情接口自动可用）

### 4. 资产写接口主动失效缓存
- `backend/app/api/v1/assets.py`：创建/更新/删除资产接口调用 `invalidate_asset_index()`（TTL 10 分钟兜底）

### 5. 前端展示
- `frontend/src/pages/AlertList.jsx`：COLUMNS（cat='资产与主体'）新增「关联资产」列，名称可点击 → `navigate('/assets/list?keyword=' + encodeURIComponent(relate_asset_ip || relate_asset_name))`；未命中显示 `--`
- `frontend/src/pages/AlertDetailDrawer.jsx`：「资产与主体」分组新增「关联资产」KV（名称 + 命中 IP），点击同样跳转
- `frontend/src/pages/Assets.jsx`：L235 `keyword` 初始化支持 URL 参数（`useSearchParams`），使跳转后自动搜索

### 6. 存量告警回填
- 一次性脚本（容器内执行后删除）：对全部 `alert_events` 用同一匹配算法回填 3 列

## 复用的现有模式
- 富化器协议：`enrich(norm, db) -> None` + `enricher_registry`（enricher_stage.py）
- `NormalizedEvent.set_field`（events.py L252）→ `to_alert_fields()` → `AlertEvent(**fields)` 自动落库
- `ensure_columns` 轻量迁移（security.py L271）
- 列定义模式：AlertList.jsx L226-234（cat='资产与主体'）
